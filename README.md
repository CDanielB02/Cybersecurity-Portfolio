## Featured Security Projects

### [01. Enterprise Network Segmentation & DMZ Firewall Lab](./01-OPNsense-Enterprise-Segmentation)
* **Focus:** Perimeter Defense & Traffic Isolation
* **Tech Stack:** OPNsense, VMware, TCP/IP
* **Summary:** Architected and validated a multi-tier enterprise network separating Untrusted WAN, Semi-Trusted DMZ, and High-Trust Internal LAN subnets. Enforced stateful filtering policies to prevent lateral movement from internet-facing assets.

### [02. Network Intrusion Detection System (NIDS) & Packet Analysis Lab](./02-Suricata-IDS-Packet-Analysis)
* **Focus:** Threat Detection & Layer 7 Packet Dissection
* **Tech Stack:** Wireshark, Nmap, Kali Linux
* **Summary:** Engineered custom detection signatures in Suricata to flag ICMP sweeps, TCP SYN port scans, and HTTP directory traversal attempts in real time. Validated alert fidelity by conducting deep packet inspection (DPI) in Wireshark.

### [03. Centralized SIEM Log Ingestion & Threat Monitoring Lab](./03-SIEM-Log-Analysis-Incident-Monitoring)
* **Focus:** Security Telemetry, Parsing Pipelines, and Incident Triage
* **Tech Stack:** Python, Hydra, Logwatch
* **Summary:** Built a real-time log parsing engine in Python to ingest host authorization streams. Simulated automated brute-force attacks and unauthorized persistence mechanisms, mapping log telemetry directly to severity scores and forensic audit summaries.
